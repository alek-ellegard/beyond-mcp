## Quick Summary

### The Problem
AI tools (like MCP Servers) make AI forget context. This repo shows 4 different approaches to building AI tools, each with different trade-offs.

### The 4 Approaches

| Approach | Best For | Context |
|----------|----------|---------|
| 🎁 **MCP Server** | External tools, standardization | ❌ Forgets |
| 🛠️ **CLI** | New tools, human + AI use | 😐 Okay |
| 📁 **Scripts** | Maximum efficiency, portability | ✅ Remembers |
| 🎯 **Skills** | Claude Code, auto-discovery | ✅✅ Best |

### The Golden Rules

1. **External tool?** → Use MCP
2. **Building new?** → Use CLI
3. **Context matters?** → Use Scripts/Skills
4. **When in doubt?** → Keep it simple!

## Key Takeaway

**There's no "best" way to build AI tools.**

It depends on:
- Who built it (you or someone else?)
- Who uses it (humans, AI, or both?)
- What matters (portability or efficiency?)
- Which AI (Claude Code or any?)

Choose the right tool for the job! 🎯
