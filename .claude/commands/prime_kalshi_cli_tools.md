# Purpose

Understand the kalshi toolset available to us and how to use them.

## Variables

KALSHI_CLI_TOOLS_PATH_DIR: `apps/2_cli`
KALSHI_CLI_TOOLS_PATH_FILE: `apps/2_cli/kalshi_cli/cli.py`

## Instructions

- Default to using `--json` flag for all commands.
- Prioritize high volume markets, series, and events.
- You can use `jq` to parse the JSON output.
- IMPORTANT: Do not read any .py files other than `cli.py`.

## Workflow

1. Read ONLY @apps/2_cli/README.md and @apps/2_cli/kalshi_cli/cli.py.
2. Run the `Report` section.
3. As you work with the user, call the right `kalshi` CLI command to get the data you need.
